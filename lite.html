带宽与内核提示：本实验室预打包了含 numpy 与 matplotlib 的本地 Pyodide 内核（首次加载约 50MB 静态资源，浏览器缓存后二次进入近乎秒开；受限网络下首开可能需要 10–30 秒）。 Kernel & bandwidth note: the local Pyodide scientific kernel bundles numpy and matplotlib (~50MB on first visit, cached by the browser thereafter; expect 10–30s on first kernel boot over slower links).
⚠️
已知限制：浏览器刷新会清空 kernel 状态（变量需重跑）；笔记本改动默认保存在浏览器存储，清缓存即丢，重要改动请及时下载备份。 Known limits: refreshing the page clears kernel state (re-run cells); edits live in browser storage and are lost when site data is cleared — download to keep changes.
